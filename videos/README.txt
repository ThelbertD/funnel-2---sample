Drop your video files (.mp4, .webm, .mov) in this folder.

Then open ../videos.js and set the matching slot, for example:

  "audit-results": "videos/results-vsl.mp4",

Hosted links (YouTube, Vimeo, Loom, Wistia) do not need a file here.
For paid traffic, hosted video (Wistia or Vimeo) loads faster than a raw file.
